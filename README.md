# Radar CAIS

Plataforma de Inteligência de Editais e Captação de Fomento em PD&I — Instituto CAIS.

## 🌐 Acesse o painel online

**https://jaimeabreu2.github.io/radar-cais/**

O painel é atualizado automaticamente todos os dias às 08h00 (horário de Brasília) pelo GitHub Actions (`.github/workflows/monitor_editais.yml`).

## O que você encontra

- Editais auditados de 19 portais oficiais (FINEP, CNPq, FUNCAP, ETICE, EMBRAPII, CONFAP, MDIC, BNDES, Horizon Europe e outros)
- Nota CAIS (0 a 10) e semáforo de decisão: **GO**, **AVALIAR** e **URGENTE**
- Exportação em CSV e relatório executivo em PDF

## Rodar localmente

```bat
iniciar_painel.bat
```
